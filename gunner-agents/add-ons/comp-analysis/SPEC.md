# Comp Analysis Add-on

**Product Name:** Comp Agent
**Price:** $79/mo
**Status:** 🔨 Designing

## Purpose

Automatically pull comps, calculate ARV, estimate repairs, and generate MAO (Maximum Allowable Offer) for properties. Gives the AM a draft offer sheet instead of starting from scratch.

---

## Agents

| Agent | Role | Responsibility |
|-------|------|----------------|
| **Comp Coordinator** | Lead | Receives valuation requests, orchestrates the workflow |
| **Comp Researcher** | Worker | Pulls comparable sales from multiple sources |
| **ARV Analyst** | Worker | Calculates ARV based on comps, adjusts for property specifics |
| **Repair Estimator** | Worker | Estimates rehab costs based on condition |
| **Offer Calculator** | Worker | Runs MAO formula, generates offer range |
| **Valuation Reviewer** | Reviewer | Sanity-checks numbers, flags outliers |

---

## Workflow

```
Trigger: Lead marked HOT or AM requests valuation
        ↓
[1] Comp Coordinator receives request
        ↓
[2] Coordinator → Comp Researcher: "Pull comps for [address]"
        ↓
[3] Comp Researcher pulls from: Redfin, Zillow, MLS (if available), county records
        ↓
[4] Coordinator → ARV Analyst: "Calculate ARV" (with comps)
        ↓
[5] ARV Analyst selects best comps, adjusts for differences, outputs ARV range
        ↓
[6] Coordinator → Repair Estimator: "Estimate repairs" (with condition data)
        ↓
[7] Repair Estimator outputs repair cost range based on condition
        ↓
[8] Coordinator → Offer Calculator: "Generate MAO"
        ↓
[9] Offer Calculator runs formula: MAO = ARV × 70% - Repairs - Assignment Fee
        ↓
[10] Coordinator → Valuation Reviewer: "Review numbers"
        ↓
[11] Reviewer flags any issues or approves
        ↓
[12] Output: Valuation packet delivered to AM (Kyle)
```
