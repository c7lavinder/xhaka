📋 OVERVIEW

This document outlines the buyer organization system for New Again Houses in GoHighLevel. The goal is to quickly identify and prioritize the right buyers when a new deal comes in.

Current Problem:
• Buyer quality tiers exist in Esteban's head, not the system
• When a deal drops, manually filtering + mental ranking slows things down
• If Esteban is out, no one knows who the priority buyers are

Solution:
• Add custom fields to capture buyer quality + key qualifiers
• Use tags for multi-select attributes (markets, buybox)
• Enable anyone to filter "Priority + Nashville + Flipper" instantly

📊 CUSTOM FIELDS (Buyer Info)

Create a new Custom Field FOLDER called "Buyer Info" with these fields:

1. BUYER TIER (Dropdown - Single Select)
   Options:
   • 🔥 Priority - Ready now, knows their stuff, verified funding, makes offers daily
   • ✅ Qualified - Has funding, actively looking, but not urgent
   • 🤝 JV Partner - Has their own buyer list, can move deals
   • ⏸️ Not Ready - Just browsing, funding unclear, needs more time
   • ❌ Dead - Unresponsive, bad fit, do not contact

2. VERIFIED FUNDING (Checkbox)
   • Check if buyer has confirmed proof of funds or financing

3. HAS PURCHASED BEFORE (Checkbox)
   • Check if buyer has closed a deal (with NAH or elsewhere)

4. RESPONSE SPEED (Dropdown - Single Select)
   Options:
   • ⚡ Fast (responds within 24 hours)
   • 🕐 Normal (responds within 2-3 days)
   • 🐢 Slow (takes a week+)

5. LAST CONTACT DATE (Date Field)
   • Track when you last spoke with this buyer

6. NOTES (Text - Multi-line)
   • Any additional context about this buyer

🔧 GHL SETUP INSTRUCTIONS

STEP 1: Create the Custom Field Folder

1. Go to Settings (gear icon) → Custom Fields
2. Click "Add Folder"
3. Name it: Buyer Info
4. Click Save

STEP 2: Create Each Custom Field

For BUYER TIER:
1. Inside "Buyer Info" folder, click "Add Field"
2. Field Type: Dropdown (Single)
3. Field Name: Buyer Tier
4. Add these options (copy exactly):
   - 🔥 Priority
   - ✅ Qualified
   - 🤝 JV Partner
   - ⏸️ Not Ready
   - ❌ Dead
5. Click Save

For VERIFIED FUNDING:
1. Click "Add Field"
2. Field Type: Checkbox
3. Field Name: Verified Funding
4. Click Save

For HAS PURCHASED BEFORE:
1. Click "Add Field"
2. Field Type: Checkbox
3. Field Name: Has Purchased Before
4. Click Save

For RESPONSE SPEED:
1. Click "Add Field"
2. Field Type: Dropdown (Single)
3. Field Name: Response Speed
4. Add options:
   - ⚡ Fast
   - 🕐 Normal
   - 🐢 Slow
5. Click Save

For LAST CONTACT DATE:
1. Click "Add Field"
2. Field Type: Date
3. Field Name: Last Contact Date
4. Click Save

For NOTES:
1. Click "Add Field"
2. Field Type: Multi-line Text
3. Field Name: Buyer Notes
4. Click Save

STEP 3: Add Missing Market Tags

1. Go to Settings → Tags
2. Check if all markets exist. Add any missing:
   - Nashville
   - Columbia
   - Chattanooga
   - Knoxville
   - Morristown
   - Tri Cities
   - Huntsville
   - Raleigh

STEP 4: Add Missing BuyBox Tags

1. Still in Tags settings
2. Check if all buybox tags exist. Add any missing:
   - Builder
   - Flipper
   - Landlord
   - Multi Family
   - Turn Key

📱 DAILY WORKFLOW

When a new buyer comes in:

1. Add to Buyer Pipeline (New stage)
2. Apply MARKET tags (can be multiple)
3. Apply BUYBOX tags (can be multiple)
4. After qualifying call, set:
   • Buyer Tier
   • Verified Funding (if confirmed)
   • Has Purchased Before (if yes)
   • Response Speed
   • Last Contact Date = today

When a new deal drops:

1. Go to Contacts
2. Filter by:
   • Tag = [Deal's Market]
   • Tag = [Deal's Property Type / BuyBox match]
   • Buyer Tier = 🔥 Priority OR ✅ Qualified
3. Sort by Last Contact Date (most recent first)
4. Blast to Priority first, then Qualified
