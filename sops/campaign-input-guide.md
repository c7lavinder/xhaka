# Campaign INPUT Quick Reference

**Who fills this out:** Jessica (Data Manager) — weekly
**Tabs:** CC, SMS, Forms, PPL, PPC, Cards, JV, Referrals Campaign INPUT

---

## Weekly Data Entry (Bottom Section)

Each week, add a new row with:

| Column | What to Enter |
|--------|---------------|
| **Date** | Week identifier (e.g., 1.6, 1.13, 1.20 for Jan weeks) |
| **Spend** | $ spent on this channel that week |
| **Calls/Texts** | Number of calls or texts made |
| **Contacts** | Number of actual conversations |
| **Leads** | Leads generated |
| **Offers** | Offers made from those leads |
| **Contracts** | Contracts signed |
| **Deals** | Deals closed |

---

## Top Section (Auto-Calculates)

**Don't edit these** — they pull from weekly data:

- **Execution Rates** — Contact Rate, Lead Rate, Offer Rate, Deal Rate
- **Location Totals** — Tennessee, Global, N/A
- **Total Row** — Sums all locations
- **Goal Row** — Set your targets here

---

## Location Split

If running campaigns in multiple markets:
- **Tennessee** = Local market data
- **Global** = Virtual/other markets
- **N/A** = Unassigned or overflow

---

## Tips

1. **Enter data same day each week** — consistency matters for rate calculations
2. **Don't skip weeks** — enter zeros if nothing happened
3. **Match dates across all tabs** — makes cross-channel comparison easier
4. **Spend = actual $ out the door** — not budgeted, not projected

---

## What Feeds the Scoreboard

The Scoreboard pulls totals from each Campaign INPUT tab:
- $ Spent
- # Sent (Calls/Texts)
- Leads
- Offers
- Contracts
- Deals
- Revenue (from Deals tab)

If Scoreboard shows wrong numbers, check the Campaign INPUT tabs first.
