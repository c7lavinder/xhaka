# KPI Spotlight Guide — Team Accountability

**Applies to:** AM Spotlight, LM Spotlight, LG Spotlight
**Owner:** Jessica (Data Manager) — enters data, monitors trends, flags issues

---

## The Three Metrics (All Spotlights)

| Metric | What It Measures | Red Flag Means |
|--------|------------------|----------------|
| **#1 — Activity (Calls/Time)** | Effort — did they show up for 8 hours? | Attendance or time management issue |
| **#2 — Connects/Conversations** | Lead quality + software + focus | Software issue, bad leads, or slacking |
| **#3 — Outcomes (Leads/Apts/Offers)** | Skill — can they convert? | Coaching opportunity |

---

## Daily Goals

- Top number = daily goal assuming a full 8-hour shift
- If someone consistently misses #1, they're either not working full days or wasting time
- If #1 is green but #2 is red, check lead quality or software
- If #1 and #2 are green but #3 is red, it's a skill/training issue

---

## Color Coding

| Color | Meaning |
|-------|---------|
| 🟥 Red | Did not meet goal |
| 🟨 Yellow | Met goal |
| 🟩 Green | Exceeded goal |

---

## Accountability Process

1. **Jessica enters data daily** from SMS lead gen, dialer software, and team inputs
2. **Jessica monitors for red trends** — one red day is fine, multiple is a pattern
3. **Jessica reaches out to team member** if red is becoming a trend
4. **Escalate to Corey** if pattern continues after initial flag
