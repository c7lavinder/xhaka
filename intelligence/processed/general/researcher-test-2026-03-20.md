# gstack — 3-Bullet Summary

- **gstack is an open-source "software factory" for Claude Code** — created by Garry Tan (YC CEO), it turns Claude Code into a virtual engineering team via slash commands that act as specialized roles: CEO strategist, eng manager, designer, QA lead, reviewer, and release engineer.

- **It enables solo developers to ship at team-of-twenty scale** — Tan reports 10,000-20,000 usable lines of code per day using gstack's structured workflows (`/office-hours`, `/plan-ceo-review`, `/review`, `/qa`, `/ship`), with 140k+ lines added in a single week across 362 commits.

- **It's free, MIT-licensed, and installs in 30 seconds** — requires only Claude Code, Git, and Bun; designed for founders, first-time Claude Code users, and staff engineers who want rigorous review, QA, and release automation on every PR.
