# Daily Checklists by Role
**Purpose:** Printable daily routines
**Status:** Draft — Feb 3, 2026

## Lead Manager (LM) Daily Checklist

### ☀️ Start of Day
- [ ] Check GHL notifications — new leads assigned?
- [ ] Review today's follow-up tasks
- [ ] Check calendar — any scheduled callbacks?
- [ ] Open script/objection reference

### 📞 Calling Block (Primary Work)
- [ ] Call new assigned leads first
- [ ] Work hot follow-ups (1-month bucket)
- [ ] Work warm follow-ups (4-month bucket)
- [ ] Complete scheduled callbacks
- [ ] Update lead statuses after each call
- [ ] Set next follow-up dates

### 📅 Appointments
- [ ] Confirm any upcoming appointments
- [ ] Update GHL calendar if changes
- [ ] Notify AM of new appointments

### 🌙 End of Day
- [ ] Enter daily numbers in KPI spreadsheet
  - [ ] Calls made: ___
  - [ ] Conversations: ___
  - [ ] Appointments set: ___
- [ ] All lead statuses updated?
- [ ] Tomorrow's follow-ups scheduled?

## Acquisition Manager (AM) Daily Checklist

### ☀️ Start of Day
- [ ] Review today's walkthrough schedule
- [ ] Prep for each appointment:
  - [ ] Property details reviewed
  - [ ] Directions mapped
  - [ ] Contract ready
- [ ] Check pending offer calls

### 🏠 Walkthroughs
- [ ] Arrive 5 min early
- [ ] Tour property, take notes
- [ ] Take photos (with permission)
- [ ] Assess repairs
- [ ] Confirm motivation
- [ ] Schedule offer call before leaving

### 📊 Analysis & Offers
- [ ] Run numbers in MasterSuite
- [ ] Prepare offers
- [ ] Make offer calls at scheduled times
- [ ] Handle negotiation/counters
- [ ] Send contracts for accepted offers

### 🌙 End of Day
- [ ] Enter daily numbers in KPI spreadsheet
  - [ ] Walkthroughs: ___
  - [ ] Offers made: ___
  - [ ] Contracts sent: ___
- [ ] Update opportunities in GHL
- [ ] Follow up on pending offers
- [ ] Alert Dispo on new contracts

## Cold Caller Daily Checklist

### ☀️ Start of Shift
- [ ] Get call list (assigned or BatchLeads export)
- [ ] Open dialer
- [ ] Script ready and visible
- [ ] Water/snacks nearby

### 📞 Calling Block
- [ ] Work through list systematically
- [ ] Mark outcomes for each call:
  - Answered
  - Voicemail
  - Bad number
  - Not interested
  - Interested → Submit
- [ ] Submit leads immediately when qualified
- [ ] Take 5-min break every hour

### 🌙 End of Shift
- [ ] Report numbers:
  - [ ] Dials: ___
  - [ ] Contacts: ___
  - [ ] Leads submitted: ___
- [ ] Note any list quality issues
- [ ] Prep for next session

## Data Manager Daily Checklist

### ☀️ Morning
- [ ] Check "New Lead" column — anything waiting?
- [ ] Process overnight leads:
  - [ ] Verify data
  - [ ] Score (5 factors)
  - [ ] Move to Warm or Hot
- [ ] Add to MasterSuite if needed
- [ ] Enter yesterday's KPIs

### 🔄 Throughout Day
- [ ] Monitor New Lead column (every 30-60 min)
- [ ] Process leads as they come in
- [ ] Answer team data questions
- [ ] Update records as needed

### 🌙 End of Day
- [ ] Final sweep of New Lead column
- [ ] Complete KPI entries:
  - [ ] LM Spotlight done
  - [ ] AM Spotlight done
  - [ ] LG Spotlight done
  - [ ] Campaign INPUT tabs updated
- [ ] Flag any issues for tomorrow
- [ ] Zero leads stuck in New Lead

## Disposition Manager Daily Checklist

### ☀️ Morning
- [ ] Check Dispo Pipeline — new deals from AM?
- [ ] Review pending buyer responses
- [ ] Check today's scheduled showings
- [ ] Follow up on quiet deals

### 📤 New Deals
- [ ] Gather deal details from AM
- [ ] Prepare blast materials:
  - [ ] Property summary
  - [ ] Photos
  - [ ] Numbers
- [ ] Send to Priority buyers
- [ ] Send to Qualified buyers
- [ ] Track responses in GHL

### 👀 Showings
- [ ] Confirm access with seller
- [ ] Confirm time with buyer
- [ ] Send access instructions
- [ ] Follow up after showing

### 💰 Closing Deals
- [ ] Collect and compare offers
- [ ] Negotiate best terms
- [ ] Get buyer under contract
- [ ] Coordinate with title company
- [ ] Track to closing

### 🌙 End of Day
- [ ] Update deal statuses in GHL
- [ ] Follow up on pending responses
- [ ] Prep tomorrow's showings
- [ ] Alert team on deal progress

## Weekly Checklist (All Roles)

### Monday
- [ ] Review last week's numbers
- [ ] Set goals for this week
- [ ] Clear any backlog from weekend

### Wednesday
- [ ] Mid-week check — on pace?
- [ ] Address any stuck deals/leads

### Friday
- [ ] Enter final numbers
- [ ] Prep anything needed for weekend
- [ ] Quick team sync (if applicable)
