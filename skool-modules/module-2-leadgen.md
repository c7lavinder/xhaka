## 2.4 Cold Caller Process

### Daily Workflow
```
Start Shift
    ↓
Load list in dialer
    ↓
Call through the list
    ↓
├── Answer → Qualify → Submit Lead (if interested)
├── No Answer → Leave voicemail, next
├── Bad Number → Skip/remove
└── DNC Request → Mark and remove
```

### Calls Per Day Target
**20+ calls per day per rep** (quality conversations, not just dials)

### Cold Call Script
```
"Hi, is this [NAME]?

This is [YOUR NAME] calling from New Again Houses. 
We're a local company that buys houses in the Nashville area.

I'm reaching out because we're interested in buying properties 
in your neighborhood. Would you have any interest in selling [ADDRESS]?"
```

### Qualifying on the Call
Listen for:
- **Motivation:** Why would they sell?
- **Timeline:** How soon?
- **Condition:** What shape is the property in?
- **Decision maker:** Can they make the call?

### When to Submit Lead
Submit to LM pipeline if:
- ✅ Expressed interest in selling
- ✅ Has a timeline (even if vague)
- ✅ Property is in our buy area
- ✅ They are owner/decision maker

### When NOT to Submit
- ❌ Zero interest
- ❌ Property outside our area
- ❌ Already listed with agent (unless flexible)
- ❌ Unrealistic price expectations (unless motivated)
- ❌ DNC request

## 2.5 Text/SMS Campaigns

### Text Campaign Flow
```
Upload List
    ↓
Send Texts (batch)
    ↓
Reply to texts (manage responses)
    ↓
├── Interested → Submit Lead
├── Not Interested → Remove
├── Question → Respond, qualify
└── Stop Request → Remove immediately
```

### Sample Text
```
Hi [NAME], this is [YOUR NAME] with New Again Houses. 
We buy houses for cash in Nashville. 
Would you consider an offer on [ADDRESS]? 
Reply YES if interested or STOP to opt out.
```

### Text Response Handling
| Response | Action |
|----------|--------|
| "Yes" / "Maybe" | Call to qualify, submit if interested |
| "No" | Thank them, remove from campaign |
| "How much?" | "Depends on condition. Can I call you?" |
| "Stop" / "Remove" | Remove immediately, mark DNC |

## 2.6 Submitting Leads

### Submit Lead Flow
```
Qualified Interest
    ↓
Submit Lead
    ↓
Lead Manual Research Campaigns
    ↓
[Automation takes over → LM gets the lead]
```

### What to Include When Submitting
- Full name
- Phone number(s)
- Property address
- Source (where the lead came from)
- Initial notes (motivation, timeline, condition mentioned)
- Best time to call

### Where to Submit
In GHL:
1. Create new contact (if not exists)
2. Add to appropriate pipeline
3. Tag with source
4. Add notes from conversation
5. Lead enters automation queue

## 2.8 Power Play Campaign

### What It Is
A focused, high-intensity calling campaign on a hot list.

### When to Use
- New list just pulled
- High-motivation segment (probate, tax sale)
- Competitive area — need to move fast

### How It Works
```
Power Play Campaign
    ↓
All callers focus on same list
    ↓
High-volume calling
    ↓
Quick lead submission
```
