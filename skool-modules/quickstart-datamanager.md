# Data Manager Quick-Start Guide
**Role:** Data Manager / Operations
**Your Job:** Keep data clean and metrics tracked
**Day 1 Read Time:** 10 minutes

---

## Your Mission
Clean incoming leads → Move them to LMs → Track team performance → Keep the machine running

You're the quality control. Bad data = wasted calls. Good data = smooth operations.

---

## The Numbers
- Process new leads within **1-2 hours** (business hours)
- **100% accuracy** on KPI entry
- **Zero** leads stuck in New Lead column overnight

---

## Your Daily Flow

### Morning
1. Check "New Lead" column in GHL — anything waiting?
2. Process overnight leads
3. Enter yesterday's KPIs in spreadsheet

### Throughout Day
1. Monitor New Lead column (check every 30-60 min)
2. Clean and classify leads as they come in
3. Answer data questions from team
4. Update MasterSuite records

### End of Day
1. Final sweep of New Lead column
2. Complete KPI entries
3. Flag any issues for tomorrow

---

## Processing New Leads

When a lead hits "New Lead" column:

```
1. Open the contact record
2. Verify data:
   - Name spelled correctly?
   - Phone number valid?
   - Property address complete?
   - Source noted?
3. Score using 5 factors:
   - Timeline (ready soon?)
   - Condition (needs work?)
   - Price (below market?)
   - Motivation (real pain?)
   - Source (quality lead source?)
4. Move to appropriate column:
   - 3+ factors = "Hot Lead"
   - < 3 factors = "Warm Lead"
5. Automation assigns LM and notifies them
```

**Speed matters** — but accuracy matters more. A mislabeled lead wastes LM time.

---

## 5-Factor Scoring

| Factor | What to Look For |
|--------|------------------|
| **Timeline** | Wants to sell within 30 days |
| **Condition** | Property needs repairs/updates |
| **Price** | Mentioned below-market price |
| **Motivation** | Real pain (divorce, inheritance, tax issues, tenant problems) |
| **Source** | High-quality source (inbound, referral, engaged response) |

**3+ factors = Hot**
**< 3 factors = Warm**

## Adding to MasterSuite

When you clean a lead:
1. Check if property exists in MasterSuite
2. If not, create new record with:
   - Property address
   - Owner name
   - Any available details (beds, baths, etc.)
3. Note MasterSuite link in GHL contact (optional)

*MasterSuite is for property analysis later — you're just getting it started.*

## Common Issues

| Problem | Fix |
|---------|-----|
| Duplicate lead | Merge in GHL (keep the one with history) |
| Missing phone | Mark as incomplete, Warm at best |
| Bad address | Try to verify, note uncertainty |
| Wrong person | Update contact, re-verify ownership |
| Lead stuck | Check if you processed it, move if needed |

---

## GHL Housekeeping

Periodic cleanup tasks:
- **Monthly:** Review 90+ day stale leads
- **After campaigns:** Clean up non-responders
- **Before imports:** Clear old test data

**Never delete:**
- Leads with appointments (past or future)
- Leads in active follow-up
- Leads tied to deals
