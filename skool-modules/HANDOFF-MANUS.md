## Key Business Context

If you need to make judgment calls, here's the business logic:

### Deal Flow
```
Cold Caller → New Lead → Data Manager cleans → 
Warm/Hot assignment → LM contacts → 
Appointment set → AM walkthrough → 
Offer made → Contract signed → 
Dispo finds buyer → Deal closes
```

### Team Roles
| Role | Does |
|------|------|
| Cold Caller | Generates raw leads |
| Data Manager | Cleans data, routes leads |
| Lead Manager (LM) | Qualifies leads, sets appointments |
| Acquisition Manager (AM) | Walkthroughs, offers, contracts |
| Dispo Manager | Finds buyers, closes deals |

### Key Metrics
- LM: 100+ dials/day, 2+ hours talk time, 2 apts/week
- AM: ~100% of apts get offers, ~20% of offers → contract
- Goal: 2-3 contracts/month

### Important Rules
- Photos required at every walkthrough
- AM logs offers only (not walkthroughs)
- LMs don't call new leads immediately — wait for Data Manager handoff
