# Visual Intelligence Index

> Every diagram generated gets an entry here. Visuals are permanent knowledge assets — not throwaway outputs.

## Format Decision Rules
- **Mermaid** → quick flowcharts, state diagrams, sequence diagrams, control-room overviews (inline, no tool needed)
- **Excalidraw** → hand-drawn style, mind maps, creative architecture, anything that needs to argue visually (skill installed ✅)
- **draw.io** → complex nested diagrams, network topologies, multi-layer systems

## Folder Structure
```
workspace/visuals/
├── diagrams/mermaid/      → .md files with mermaid code blocks
├── diagrams/drawio/       → .drawio files
├── diagrams/excalidraw/   → .excalidraw files
├── control-rooms/         → dashboard/monitoring visuals
├── maps/                  → knowledge/system maps
└── exports/               → PNG/SVG exports
```

## Workflow (Every Visual)
1. memory_search on topic before creating

3. Generate + save to correct folder with timestamped name
4. Append entry to this INDEX
