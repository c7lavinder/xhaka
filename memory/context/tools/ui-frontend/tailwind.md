# Tailwind CSS

## What It Is
A utility-first CSS framework that lets you build designs directly in markup without writing custom CSS.

## How Corey Uses It
Styling layer for Gunner's React frontend — all UI components (dashboard, call cards, leaderboard, KPI tables) are styled with Tailwind utility classes.

## Pricing
Free — open-source. Tailwind UI (component library) is a paid add-on ($149 one-time) but not required.

## Key Links
- Docs: https://tailwindcss.com/docs
- Changelog: https://tailwindcss.com/blog
- GitHub: https://github.com/tailwindlabs/tailwindcss

## Alternatives Worth Watching
- shadcn/ui — built on Tailwind + Radix, already likely used for Gunner components; not a replacement but a companion
- UnoCSS — atomic CSS engine, faster build times, drop-in alternative if Tailwind slows the build
