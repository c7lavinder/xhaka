# Vite

## What It Is
A next-generation frontend build tool that provides instant dev server startup and fast HMR (Hot Module Replacement).

## How Corey Uses It
Gunner's frontend build toolchain — replaces Create React App. Handles bundling, TypeScript transpilation, and dev server for the React UI.

## Pricing
Free — open-source.

## Alternatives Worth Watching
- Turbopack (Next.js bundler) — faster in some benchmarks, relevant if Gunner migrates to Next.js
- esbuild — the engine Vite uses under the hood; rarely used directly but worth knowing
