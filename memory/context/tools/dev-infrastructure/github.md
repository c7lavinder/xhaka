# GitHub

## What It Is
Version control and collaboration platform — hosts code repos, CI/CD workflows, and issue tracking.

## How Corey Uses It
Hosts the Gunner codebase (`c7lavinder/xhaka` for Xhaka memory, Gunner repo for the app). Sentry auto-creates GitHub issues when production errors occur. Xhaka agents use the API to commit memory files and tool profiles. Token: xhaka-deploy (repo + workflow + read:org scope).

## Pricing
Free tier covers private repos and GitHub Actions minutes for small teams. Likely on Free or Team ($4/user/mo).
