# Vercel

## What It Is
Frontend cloud deployment platform optimized for Next.js, React, and static sites with edge functions.

## How Corey Uses It
Potential deployment target for Gunner's frontend — not yet confirmed as active. Currently Railway hosts the backend; Vercel would handle the React/Vite UI layer if separated from the monorepo.

## Pricing
Hobby: Free (personal projects). Pro: $20/user/mo (team + custom domains + more build minutes).

## Key Links
- Docs: https://vercel.com/docs
- Changelog: https://vercel.com/changelog
- GitHub: https://github.com/vercel/vercel

## Alternatives Worth Watching
- Netlify — comparable feature set, slightly different DX; strong for static sites
- Railway (already in use) — could host frontend too, avoiding a second platform
