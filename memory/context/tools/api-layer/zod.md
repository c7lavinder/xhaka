# Zod

## What It Is
A TypeScript-first schema declaration and validation library that ensures runtime type safety.

## How Corey Uses It
Validates all incoming data in Gunner — GHL webhook payloads, API request bodies, environment variables. Works hand-in-hand with tRPC to give end-to-end type safety from frontend to backend.

## Pricing
Free — open-source.
