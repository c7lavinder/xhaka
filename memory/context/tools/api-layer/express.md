# Express

## What It Is
A minimal, unopinionated Node.js web framework for building HTTP servers and REST APIs.

## How Corey Uses It
Gunner's backend HTTP layer — handles webhook endpoints (GHL call events), REST routes, and middleware (auth, logging). Likely the foundation that tRPC runs on top of.

## Pricing
Free — open-source.

## Alternatives Worth Watching
- Fastify — drop-in Express alternative with significantly better performance and built-in TypeScript support
- Hono — ultra-lightweight, edge-compatible; worth watching for future Railway/edge deployments
