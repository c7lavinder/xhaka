## How to Deepen a Tool
1. Add to `intelligence/tool-research-inbox.md` with format: `- ToolName | https://docs.url.com | category`
2. Researcher job picks it up on next run (or trigger manually via task queue)
3. Knowledge lands in `memory/context/tools/{category}/{tool-slug}/knowledge/overview.md`
4. Update this INDEX — change status from 🔴/🟡 to 🟢

## Knowledge Directory Structure
```
memory/context/tools/
  {category}/
    {tool-slug}/
      knowledge/
        overview.md        ← auto-generated by tool-researcher job
        official-docs.md   ← (optional) raw doc excerpts
        setup-guide.md     ← (optional) step-by-step for our stack
        best-practices.md  ← (optional) patterns + recommendations
        gotchas.md         ← (optional) warnings + rate limits
```
