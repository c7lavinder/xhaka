# WaveSurfer.js

## What It Is
A JavaScript library that renders interactive audio waveform visualizations in the browser using Web Audio API and Canvas.

## How Corey Uses It
Powers the call playback UI in Gunner — displays waveform visualization of recorded sales calls so users can scrub through calls, see AI-flagged moments, and play back specific segments during coaching review.

## Pricing
Free — open-source (BSD-3 license).
