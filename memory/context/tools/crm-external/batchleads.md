# BatchLeads

## What It Is
A real estate data and SMS marketing platform for skip tracing, list building, and outbound text campaigns.

## How Corey Uses It
NAH's SMS outreach platform — sends text blasts to motivated seller lists. API key used by Xhaka to pull SMS metrics (sent, replies, opt-outs) for daily KPI Entry.

## Pricing
Paid subscription — tiered by SMS credits and contacts. Exact NAH tier not documented.
