# CallRail

**Category:** CRM & External
**Status:** 🟢 Active

## Purpose
Call tracking and voicemail processing. Captures inbound calls and voicemails from marketing channels, used by the Voicemail Bot to pull and process missed calls.

## Usage in Stack
- Voicemail Bot pulls voicemail recordings via API
- Call logs used for attribution tracking
- API key configured
