# Resend

## What It Is
A developer-focused transactional email API built for reliability and React-based email templating.

## How Corey Uses It
Sends transactional emails from Gunner — password resets, call report summaries, team notifications. Pairs with React Email for templated HTML emails. Likely the primary send layer vs Loops (which handles lifecycle/marketing flows).

## Pricing
Free: 3,000 emails/mo, 1 domain. Pro: $20/mo for 50,000 emails/mo. NAH volume almost certainly fits Free tier.
