## Major Architecture Shift: 5 Execution Bots
Corey drove a fundamental rearchitecture — separate intelligence (agents) from execution (bots).

**5 Execution Bots (all deployed):**
1. **Call Summary** → `addContext()` — notes/context — ✅ ACTIVE
2. **Task Manager** → `createTask()` — tasks + dedup — ✅ ACTIVE
