### Gunner Add-on Model
- Each add-on = separate purchase ($29-79/mo)
- Billing-gated: agents only run for paying tenants
- Tenant connects GHL via OAuth
- Tenant configures their own rules (NAH's rules = defaults)
- When billing lapses, agents stop (grace period 3-7 days)

### Timeline Discussion
- One workflow A-Z (trusted): 6-8 weeks
- Full suite (5 workflows): 4-5 months
- "Trust" comes from iteration, not initial build
