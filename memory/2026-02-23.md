## Lessons Learned Today
- GHL v2 API is strict: every search endpoint needs `location_id`, conversation create returns 400 on duplicate
- Contact standard fields (phone, email, name) are top-level CRM properties — NOT in customFields. Always merge them into context.fields
- `gemini-1.5-flash` is dead in v1beta — use `gemini-2.0-flash`
- Postgres timestamps come back as JavaScript Date objects from node-postgres, not strings — must cast with `(row.timestamp as unknown as Date).toISOString()`
- The Guard idempotency check is crucial — it was the reason initial outreach silently skipped (hard-stop on no phone hit instantly)
- Dry-run mode needs to bypass BOTH Guard idempotency AND OutboundManager dedup to work correctly
