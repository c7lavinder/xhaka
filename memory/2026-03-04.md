# 2026-03-04 — The Infrastructure Pivot

## 🚨 Critical Architecture Shift
**Problem:** The current system is "building the bridge while walking on it." V1 breaks constantly because of flaky GHL OAuth, direct webhook dependencies, and lack of a staging environment. Real leads are at risk during debugging.
**Solution:** Stop feature dev. Build the **Foundation** first.

### 1. Gunner Bridge (The Connectivity Layer)
*   **Mission:** A dedicated microservice to handle the "dirty work" of GHL connectivity.
*   **OAuth:** Auto-refreshing tokens stored in Redis. No more 3 AM expiry failures.
*   **Webhooks:** Ingestion Queue (BullMQ) + Worker. Handles bursts/downtime without losing data.
*   **Spec:** `gunner-backend/docs/gunner-bridge-spec.md` (Delivered).

### 2. Gunner Core (The Data Pump)
*   **Mission:** 100% Accurate Local Mirror of GHL Data.
*   **Strategy:** Hybrid Sync (Real-time Webhooks + Safety Net Polling).
*   **Benefit:** Triggers run against *local* DB (instant/reliable), not flaky GHL API.

### 3. Staging Environment
*   **Rule:** No more coding in Production during the day.
*   **Setup:** `GUNNER_ENV=staging` pointing to a Test GHL account.
*   **Workflow:** Break Staging -> Fix -> Deploy to Production.
